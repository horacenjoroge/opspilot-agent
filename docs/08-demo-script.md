# Demo Script

## Goal

Keep the demo under 3 minutes and show an engineering workflow rather than a chat exchange.

| Time | Scene |
|---|---|
| 0:00-0:20 | Explain the incident triage problem for small engineering teams |
| 0:20-0:45 | Create a demo incident from a seeded scenario |
| 0:45-1:25 | Show the agent triaging with Qwen-powered structured reasoning and approved tools |
| 1:25-1:55 | Present diagnosis and recommended remediation |
| 1:55-2:20 | Show human approval for a risky action |
| 2:20-2:40 | Show simulated remediation and audit timeline |
| 2:40-3:00 | End on the architecture, highlighting Qwen Cloud and Alibaba Cloud |

## Required Story Beats

- The agent uses Qwen for reasoning, not direct execution.
- Tool calls are visible and explainable.
- Risky remediation pauses for approval.
- The backend records an audit timeline.

## Demo Emphasis

The main scenario should be `high_api_error_rate` because it clearly demonstrates investigation, diagnosis, approval, and simulated remediation in a way judges can follow quickly.
