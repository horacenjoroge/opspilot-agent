What OpsPilot Does

OpsPilot helps engineers triage incidents, inspect evidence, recommend safe remediation, and preserve reusable incident memory — without letting the LLM directly control infrastructure. The model reasons; the backend enforces every constraint.

Qwen Cloud's Role

Qwen is used for triage classification, tool planning, diagnosis, remediation recommendation, and final report generation. Every response must be strict JSON before the backend uses it. Qwen never executes anything directly.

Tool System

The model never executes infrastructure actions directly. It recommends allowlisted tool names. The backend validates the names against the allowlist, runs the tools in sequence, and stores every output in the timeline as auditable evidence.

Triage phase is restricted to investigation tools only — remediation tools cannot be called during evidence collection.

Approval Gate

The backend risk policy — not the model — decides whether an action is safe, medium, or dangerous. Dangerous actions always create an approval request and halt execution. The model cannot bypass this gate regardless of its reasoning.

Approvals can be actioned from the UI, the REST API, or programmatically — enabling integration with Slack bots or runbook automation.

Evaluation Harness

OpsPilot includes seeded evaluation scenarios that run through the same backend workflow and return PASS or FAIL on expected severity classification, tool usage, and final incident status — so judges can verify repeatability without manual steps.
