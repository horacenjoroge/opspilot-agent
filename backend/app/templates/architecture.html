System Explainer

Why OpsPilot is an agent, not a chatbot

OpsPilot is a backend-controlled incident workflow. Qwen proposes structured decisions, but the backend validates tools, stores evidence, applies policy, pauses for approval, and records everything in a timeline.

What OpsPilot Does

OpsPilot helps engineers triage incidents, inspect evidence, recommend safe remediation, and preserve reusable incident memory without letting the LLM directly control infrastructure.

Qwen's Role

Qwen is used for triage, tool planning, diagnosis, remediation recommendation, and final report generation. Every response must be strict JSON before the backend uses it.

Tool System

The model never executes infrastructure actions directly. It can only recommend allowlisted tools. The backend validates the names, runs the tools, and stores the outputs in the timeline.

Approval Gate

The backend risk policy, not the model, decides whether an action is safe, medium, or dangerous. Dangerous actions always create an approval request before any remediation can proceed.

Evaluation Harness

OpsPilot includes seeded evaluation scenarios that run through the same backend workflow and return PASS or FAIL results so teams can inspect repeatability quickly.
